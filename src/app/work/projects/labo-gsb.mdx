## Contexte

Projet pédagogique (BTS SIO option SISR) : refonte de l'infrastructure réseau du site parisien du
laboratoire pharmaceutique **GSB**. L'objectif : concevoir une architecture **segmentée par VLAN**,
sécurisée et adaptée à l'organisation de l'entreprise, puis la **maquetter sous Cisco Packet Tracer**.

## Objectifs

- Analyse des besoins et des exigences réseau du site
- Architecture segmentée en **12 VLAN** (un par service)
- **Plan d'adressage IP** optimisé par VLSM (réseau 172.16.0.0)
- **Routage inter-VLAN** (router-on-a-stick, 802.1Q)
- Services réseau : **DHCP** (relais `ip helper-address`) & **DNS**
- **Sécurisation** des flux inter-VLAN par **ACL**

## Routage inter-VLAN (extrait — routeur R1)

```bash
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 172.16.1.62 255.255.255.192
 ip helper-address 172.16.0.125

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 172.16.1.222 255.255.255.224
 ip helper-address 172.16.0.125

router rip
 version 2
 network 172.16.0.0
 network 172.16.1.0
```

## Sécurisation par ACL (extrait)

```bash
! La Direction/DSI (VLAN 20) ne peut pas accéder à RH/Compta (VLAN 30)
access-list 101 deny ip 172.16.1.192 0.0.0.31 172.16.0.192 0.0.0.63
access-list 101 permit ip any any

interface GigabitEthernet0/0.20
 ip access-group 101 in
```

## Résultat

Une maquette **fonctionnelle** sous Cisco Packet Tracer : 12 VLAN routés, attribution automatique
des adresses (DHCP), résolution de noms (DNS) et cloisonnement des services sensibles par ACL.
